# Teleagent
Bridge local entre agentes Cursor e Telegram — alertas e decisões humanas no loop, por projeto.

Teleagent é um bridge local que conecta agentes do Cursor ao Telegram. Quando um agent precisa te alertar ou pedir uma decisão, ele manda mensagem no Telegram, espera sua resposta e continua sozinho — com contexto do projeto em que está atuando.
