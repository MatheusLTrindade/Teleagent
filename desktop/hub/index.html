Documentação

			
    
				
  1. 
					Crie o bot no @BotFather (/newbot) e copie o token.
				
    2. 
				
  2. 
					Cole o token na aba Configurar e salve. Opcional: allowlist com seu
					user id do Telegram.
				
    3. 
				
  3. 
					Na aba Início, inicie o serviço e marque Iniciar com o Windows se
					quiser autostart.
				
    4. 
				
  4. 
					Abra o bot no Telegram e envie /start para vincular o chat.
				
    5. 
				
  5. 
					Use Testar para mandar um alerta de prova. Se chegar no Telegram, o
					bridge está ok.
				
    6. 
			

			
CLI (Cursor, Claude, Codex, etc.)

			

				Qualquer agent que rode shell na sua máquina pode usar o Teleagent.
			

			
teleagent alert --project meu-app --message "Build ok" --json
teleagent ask --project meu-app --question "Promovo?" --options "sim,não" --json
teleagent status
